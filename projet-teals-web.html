Teals Web

Un projet entrepreneurial de création de sites web et de prestations informatiques, mené à partir des besoins du client.

Type
Projet entrepreneurial
Technologies
HTML, CSS, PHP, SQL
Périmètre
Conception, intégration, données
État
Réalisations en dépôts privés

01Présentation

Teals Web regroupe mon activité de création de sites web et de prestations informatiques. L’idée est de partir du besoin réel du client pour concevoir une interface claire, l’intégrer proprement et la relier à une base de données quand c’est nécessaire.

02Démarche

03Compétences mises en œuvre

  • Développement de sites web.
  • Intégration frontend en HTML et CSS.
  • Développement côté serveur en PHP.
  • Gestion de bases de données.
  • Réflexion sur les besoins clients.
  • Conception d’interfaces.

04Réalisations

Le code de plusieurs sites se trouve dans des dépôts privés, notamment :

  • un site e-commerce en PHP : catalogue de produits, fiche produit, panier, compte client, espace d’administration et pages légales ;
  • un site vitrine multipage en HTML et CSS : pages de services, pages légales et sitemap.

Ces dépôts sont privés et je n’y expose ni noms de clients, ni données. Je peux présenter le code et la démarche lors d’un échange : me contacter.

05État réel du projet

Projet entrepreneurial. Aucune démonstration publique n’est référencée sur cette page, et je n’y présente que ce qui existe dans mes dépôts.
