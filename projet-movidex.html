MoviDex

Une application React pour découvrir des films, les rechercher et voir sur quelles plateformes les regarder en France, construite autour de l’API TMDB.

Type
Projet personnel d’apprentissage
Technologies
React 19, React Router, Tailwind CSS, Vite
Données
API The Movie Database (TMDB)
État
Fonctionnel · code public

Voir le code sur GitHub

01Présentation

MoviDex est un projet personnel créé pour me familiariser avec React et Tailwind CSS. L’application permet de parcourir des films, d’afficher leurs informations et de voir où les regarder, à partir des données de l’API TMDB.

Elle ne stocke aucune donnée : elle consomme l’API et affiche le résultat dans une interface simple et responsive.

02Problématique & objectif

Comment retrouver rapidement les informations d’un film et savoir où le regarder en France ?

Objectif : pratiquer React (hooks, état, props), comprendre et manipuler une API externe (fetch, async/await) et créer un projet complet à partir de zéro, de l’interface jusqu’aux données.

03Fonctionnalités

  • Films populaires affichés sous forme de grille d’affiches, avec pagination.
  • Recherche par titre avec liste de suggestions.
  • Fiche détaillée : titre, accroche, synopsis, date de sortie, durée, note, nombre de votes et budget lorsqu’il est renseigné.
  • « Où regarder ? » : plateformes de streaming, de location et d’achat disponibles en France, avec leurs logos.
  • Interface responsive grâce à Tailwind CSS.

04Travail réalisé

  • Conception de l’interface et des écrans : accueil, fiche d’un film, page à propos.
  • Découpage en composants réutilisables : barre de navigation, recherche, pagination, pied de page.
  • Mise en place du routage avec React Router.
  • Écriture de la couche d’accès à l’API TMDB et de l’affichage dynamique des données.

05Choix techniques

Une couche d’accès unique à l’API

Toutes les requêtes passent par une fonction tmdbFetch dans lib/tmdb.js : elle construit l’URL, ajoute la clé et la langue, et lève une erreur explicite si la réponse HTTP n’est pas valide. Les pages n’appellent que des fonctions métier comme getPopular ou getMovieDetails.

Configuration hors du code

La clé d’API et la langue sont lues depuis des variables d’environnement Vite, plutôt que d’être écrites dans les sources.

Disponibilité filtrée sur la France

La réponse de l’API couvre plusieurs pays ; l’application ne conserve que les résultats français et gère le cas « aucune plateforme disponible ».

Piste d’amélioration

Comme toute application purement frontend, la clé d’API est visible depuis le navigateur. Passer par un petit backend intermédiaire serait l’évolution naturelle.

07État & accès

Le projet est fonctionnel et son code est public. Pour l’exécuter en local : cloner le dépôt, installer les dépendances avec npm install, renseigner une clé d’API TMDB dans un fichier .env, puis lancer npm run dev.
