Invest Intelligence

Une application personnelle d’analyse et de suivi des marchés financiers, conçue de bout en bout : interface, API, base de données, automatisations et notifications.

Type
Projet personnel
Frontend
React, Vite, Tailwind CSS
Backend
Node.js, Express, SQLite
Intégrations
API financières, Reddit, ntfy

01Présentation

Invest Intelligence est une application que j’ai conçue pour suivre des marchés et des titres. Elle collecte des données financières, les analyse selon plusieurs catégories de signaux, exploite des données communautaires issues de Reddit et lance des scans automatisés dont les résultats sont envoyés par notification.

C’est mon projet le plus complet côté architecture : il m’a fait travailler sur la séparation frontend / backend, la persistance des données et le fonctionnement dans la durée d’un service automatisé.

02Problématique & objectif

Suivre des marchés suppose de croiser des sources de nature différente : données financières, signaux, discussions communautaires.

Objectif : centraliser la collecte, l’analyse et le suivi dans une seule application, et automatiser les scans pour être prévenu par notification.

06État réel du projet

Projet personnel à usage privé : le code n’est pas publié sur mon GitHub public. L’application est un outil d’analyse et de suivi ; je ne présente ici ni performance financière ni résultat chiffré, et rien de ce projet ne constitue un conseil en investissement.
